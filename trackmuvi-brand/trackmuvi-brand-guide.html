Identidad visual

TrackMuvi

Sistema de marca para la app de descubrimiento y seguimiento de películas y series. Un ícono simple y reconocible a tamaño pequeño, un color con carácter, y una tipografía geométrica que se siente moderna sin caer en genérica.

Concepto

El triángulo de play + el check

El ícono combina un triángulo de reproducción (películas/series) con una insignia circular de check (seguimiento/progreso) en dorado — el gesto de "marcar como visto" convertido en símbolo. Es reconocible incluso a 48px, y el check dorado funciona como acento que puedes reutilizar en la UI para estados "completado" o "en seguimiento".

Color

Paleta

El índigo es el color de marca — úsalo para acciones primarias, el ícono y cualquier elemento que necesite decir "esto es TrackMuvi". El dorado es un acento de uso puntual: estados de progreso, insignias, destacados — nunca como color base de una pantalla.

Tipografía

Space Grotesk + Inter

Space Grotesk para títulos y el wordmark — geométrica, con carácter técnico, evita sentirse como una fuente de sistema genérica. Inter para todo el texto de interfaz — probada para legibilidad en pantallas pequeñas. Ambas son gratuitas en Google Fonts.

Espacio de protección y tamaño mínimo

Reglas de uso del ícono

  • Espacio de protección mínimo: el ancho de la insignia dorada de check alrededor de todo el ícono. No coloques texto ni otros elementos dentro de ese margen.
  • Tamaño mínimo recomendado: 32px de alto para el ícono solo, 24px de alto para el lockup completo con texto.
  • Por debajo de 32px, usa solo el triángulo de play (sin la insignia de check) para mantener claridad — así está construido icon-notification.svg.
Qué sí / qué no

Uso correcto del logo

✓

Usa la versión de fondo correcta (clara u oscura) según el contraste disponible.

✕

No recolorees el ícono ni lo pongas sobre gradientes ajenos a la marca.

✓

Mantén las proporciones del ícono al escalar — es un solo objeto, no despieces sus partes.

✕

No distorsiones, inclines ni aplastes el ícono ni el wordmark.
